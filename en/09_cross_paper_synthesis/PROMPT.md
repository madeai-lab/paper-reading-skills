# Stage 09 | Use evidence at its actual scope

Start from the proposed synthesis sentences, not an average paper score. List every candidate and its current tier (`tiers`), version and target. A deferred paper is missing evidence, not evidence of absence. Separate two questions: **what did the source support, and was this use independently checked?**

| Intended use | Evidence to inspect | How to label it |
|---|---|---|
| Background or author position | Identified source and actual attribution; distinguish an abstract from a result | `SCREENING_LIMITED / BACKGROUND`; not verified |
| Method classification | Current L2 local claim; method and necessary definitions, context, diagram or boundary cases read in full | `SCOPED_L2 / CANDIDATE`, `use_kind: METHOD`; source-checked within scope, no independent review by default |
| Performance comparison | Current L2 claim plus original result, metric, baseline, data/budget conditions, notes and contrary results | `SCOPED_L2 / CANDIDATE`, `use_kind: COMPARISON`; carry limitations, not a whole-paper ranking |
| Mechanism credited with an effect | As above **and** a control or ablation isolating that change. Otherwise narrow the sentence to a configuration comparison or report a gap | `use_kind: MECHANISM_EFFECT` only when the attribution survives this check |
| A conclusion supporting the review's main argument | The above evidence **plus** independent, source-based reinspection of this wording and each supporting local claim | `SCOPED_L2 / CONCLUSION`, identified reviewer and scope. If unavailable, withhold the conclusion or present an explicitly unreviewed candidate |
| A claim presented as coming from a fully accepted reading | Currently accepted L3 run, scope and independent review mode disclosed, claim permitted by `allowed_use` | `ACCEPTED`; only COMPLETE_PAPER and current G3 allow “whole paper verified” |

Do not relabel the same main-line conclusion as a candidate to avoid review. An independent check cannot add a missing control. Keep unresolved contradictions and negative results visible. HOLD is not evidence for a conclusion. Do not pool incomparable metrics, count the same system twice or certify external novelty from this corpus.

**Scoped use procedure.** Save the assertion in `09_synthesis_claims.json` with `synthesis_claim_id`, `writer_id`, precise `text`, `evidence_basis`, `strength`, `use_kind`, `limitation` and `support`. Each scoped support names `paper_id`, `local_claim_id`, `source_sha256`, the local claim's `attribution` and `evidence_state`, plus `checks`: short source-specific descriptions for the checks above (`mechanism, context`; `result, metric, baseline, conditions`; additionally `control_or_ablation` for an effect). Cite the local items and version in the readable text. Only current, target-applicable SUPPORTED or LIMITED local claims qualify. A changed target needs reassessment before candidate use.

Example sentence: “Table 2 reports higher accuracy for the full configuration on this split.” It may qualify as a bounded comparison. “Coordination caused the improvement” does not follow if the tools also changed. A literature-wide inference absent from the sources needs its own analysis and independent review, not just matching claim IDs.

Run `check-synthesis WS --file 09_synthesis_claims.json`; inspect `valid` and each `scoped_uses` binding. For a main-line use give a distinct reviewer the exact sentence, referenced items, version, conditions, counterevidence and unresolved questions. They open the original passages/pixels and test the inference independently. One reviewer can check a batch of related claims. Record their actual judgement in a separate paper-relative `scoped_reviews/*.json` per support: `kind: SCOPED_CLAIM_REVIEW`, `binding_sha256` from the checker, `reviewer_id`, `independence_disclosure`, `source_observation`, `limits`, `decision` (`SUPPORTS_WITHIN_SCOPE` or `WITHHOLD`). Link it as `support[].review_ref`, keep negative findings, then recheck. A changed assertion, support, version, pass or target needs new inspection; no Owner self-approval. The checker verifies references and bindings, not scientific sufficiency or reviewer authenticity. This receipt is not an 08 review of a paper; never ingest it into G3.

Deliver `09_synthesis.md`, `09_synthesis_claims.json`, `09_user_review.md` and `09_coverage_summary.json` when synthesis is requested. Keep the legacy accepted-packet/08 route for formal synthesis and the existing `SCREENING_LIMITED` candidate format. Do not present mixed-tier synthesis as an accepted complete corpus.
