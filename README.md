# Paper Reading Skills / 论文精读技能

[中文](#中文) | [English](#english)

## 中文

本仓库提供双语论文完整精读技能：覆盖源文献、方法、实验、图表和证据，配合独立审查与修复流程。入口为 [SKILL.md](paper-reading-verification-v2/SKILL.md)。

将 `paper-reading-verification-v2` 文件夹安装到支持 SKILL.md 的助手技能目录，或直接向助手提供该入口和论文路径。运行前请阅读入口及对应语言的执行规范。脚本使用 Python；实际论文阅读和独立审查需要具备相应能力的助手。

仓库不包含论文 PDF、阅读结果、个人研究记录或访问凭据。自动检查只能验证结构，不能证明科学理解或替代独立审查。

## English

A bilingual skill for complete source-grounded paper reading, evidence tracking, independent review and repair. Start with [SKILL.md](paper-reading-verification-v2/SKILL.md). Install the directory in a compatible agent's skills folder or provide the entry point and a paper path to the agent. Python powers the local helpers; paper interpretation and independent review require capable agents. Automated checks do not establish scientific understanding.
