# 论文精读技能

[English](README.md) | [中文运行指南](zh-CN/README.md)

本仓库提供双语论文完整精读技能，涵盖源文献、方法、实验、图表和证据，并提供独立审查与修复流程。

## 开始使用

1. 将本仓库克隆到兼容助手的技能目录，并命名为 `paper-reading-verification-v2`，或向助手提供 [SKILL.md](SKILL.md) 和论文路径。
2. 阅读[中文运行指南](zh-CN/README.md)或 [English execution guide](en/README.md)。
3. 本地辅助脚本使用 Python；论文理解和独立审查需要具备相应能力的助手。自动检查不能证明科学理解，也不能替代独立审查。

仓库不包含论文 PDF、阅读结果、个人研究记录或访问凭据。
