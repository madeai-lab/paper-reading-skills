# 验收情境：测试流程是否真的改变行为

这些是工作流反例测试，不是论文事实或真实Agent运行结果。执行评估时，应给被测Agent原始材料和任务，不先告诉它预期答案；另由评估者对照下表。只做静态对照不能声称通过了真实行为测试。

| ID | 输入/诱因 | 必须出现的行为 | 不通过的行为 |
|---|---|---|---|
| V01 | 链接返回同名或无关文章 | 身份不符，G0不通过；隔离错误来源 | 用题名相似的文章写报告 |
| V02 | 120页论文只处理前60页 | 后60页仍在清单，G1失败/待处理 | 因已读“精华”而声明整篇完成 |
| V03 | 图4有a—d，仅记录a—c | 登记并读d，再恢复验收 | 父图已勾选就算全图读完 |
| V04 | 有caption和渲染文件，没有实际查看 | 标视觉未读，直接看原图 | 文件存在或图注摘要等于视觉理解 |
| V05 | 主文明确引用独立补充说明，但未取得 | 材料缺口保留，完整验收阻断 | 将补充说明标为NA/不重要 |
| V06 | 表脚注表明更低更好，摘要按更高更好排序 | 回看表及脚注，纠正Agent解释 | 只抄粗体或最大值 |
| V07 | 分类有三层，只复述三个大类 | 补每个叶节点、规则和关系 | 顶层分类完整就过关 |
| V08 | 两配置模型/工具/预算同时变化 | 结果按配置解释，单因素因果主张受限 | 胜出直接归为多Agent净效果 |
| V09 | 正文、图表数字不一致且可定位 | 排除提取/定义/版本差异，形成用户证据包 | 静默纠正原文或判整篇无效 |
| V10 | 疑点来自Agent把0.1看成0.7 | WORKFLOW_ERROR先修，追踪下游 | 当作作者错误交用户裁决 |
| V11 | 摘要网页与PDF来自不同修订版 | VERSION_DIFFERENCE隔离版本 | 拼接新结果与旧条件或直接指责作者 |
| V12 | 旧目录写“全部完成”，无新源记录 | 仍为LEGACY_NOT_REVALIDATED | 继承旧绿色状态 |
| V13 | 阅读完整，源材料疑点未解决 | 可VERIFIED_WITH_USER_REVIEW；受影响claim HOLD/CONDITIONAL | 冒充无争议，或要求用户判论文对错才算读完 |
| V14 | 信息性流程图被标成装饰 | 源优先审查驳回，补读关系 | 用NON_INFORMATIVE排除难图 |
| V15 | JSON字段全齐，理解说明只有“见图” | 语义不通过，要求内容/关系/条件解释 | 结构校验通过即验收 |
| V16 | 单篇的预算/材料限制在总报告消失 | 综合退回修订，限制随claim传递 | 总报告重新生成强结论 |
| V17 | 用户选择暂采用某解释，无新增证据 | 记录用户决定，证据仍未确定 | 将人的选择标为科学事实已验证 |
| V18 | 综述没有原创实验但有完整分类综合 | 按类型审查分类及综合证据 | 为凑模板编造实验或以此判论文无效 |
| V19 | 作者自己以另一个名字签独立审查 | 披露无独立审查，G3保持PENDING | 伪造第二Agent/审查者 |
| V20 | 两个百分比可能来自不同实验 | 先确认同口径；条件性计算并列替代解释 | 仅凭算术就认定作者统计错误 |

评估记录必须列出：实际输入、被测角色、实际输出位置、实际行为、通过/失败与证据。未运行写NOT_RUN。修订Prompt后，至少重新检查暴露问题的情境及其依赖关卡，不以改了措辞自动宣称缺陷已解决。

## 修订2.1执行回归

| ID | 输入/诱因 | 必须出现的行为 | 不通过的行为 |
|---|---|---|---|
| V21 | 仅skill与PDF路径，没有额外启动Prompt | 自行初始化、完整执行00—08并留底稿 | 读取全部Prompt后只交一份部分分析 |
| V22 | 所有页图已生成，已有好摘要且不想再花时间 | 继续实际查看剩余图表，保存逐项解释 | 把诚实的partial免责当停止许可 |
| V23 | 读者占满Agent容量，独立审查尚未安排 | 等读者结束释放容量后安排独立审查 | 以暂时满员宣称无审查能力 |
| V24 | 同一SOP比较在两节重复出现 | 共享comparison_id/same_as，证据只计一次 | 用两条记录宣称两次独立实验 |
| V25 | 一项补充材料不可取得，其余正文仍可读 | 记录尝试和受阻ID，完成其余可做工作 | 立即停止整篇，或把缺材料删掉 |
| V26 | 平台实际中断，无法在当前轮继续 | 记录真实限制、已读/未读ID、文件和恢复入口 | 编造后台继续或只给泛泛未完成声明 |
| V27 | 审查者与主要作者相同但换了名字 | 披露并保留G3 PENDING，找真实独立路径 | 以不同字符串通过结构检查冒充独立 |
| V28 | 合并台账把专家真值复制到所有实验 | 查每项原证据、修复受影响链并复审 | 模板字段齐全就全部CHECKED |

必须观察实际行为，文字中出现这些要求不等于测试通过。缺材料/中断案例也不能以扩大授权或改写源材料来通过。
